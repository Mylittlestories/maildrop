  How this is different from WeTransfer: there is no MailDrop service. The bytes travel from your browser directly to a temporary host (or to your own bucket), and the email carries only a link whose #part holds the manifest — hashes are never sent to a server, so nothing about your file is logged anywhere.
  Recipients click once, save, done.
  
Free public hosts rate-limit and cap sizes; expect ~1 GB per part. For daily use, wire up a bucket and the cap becomes the bucket's.
  
Everything here is static files: index.html + lib/*.js. Push to a GitHub repo, enable Pages, done — deploy guide,
